# citation-manager

## Workflow
1. Input: title, authors, year, venue, doi/url.
2. Output BibTeX entry with clean key `lastnameYearkeyword`.
3. Also output APA 7th and MLA 9th one-liners.
4. Validate: no missing braces, escape `& % $ # _`.

## Example key
`vaswani2017attention` for Attention Is All You Need.
